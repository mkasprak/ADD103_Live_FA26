# Emoji Lexicon (ADD 103)

We use emojis in HTML/CSS comments as quick “labels” so you can scan for the kind of note you need.

| Emoji | What it usually means in our code comments |
| --- | --- |
| 🎨 | Colors / palette / theme choices |
| 🛠 | Setup / reset / “plumbing” code |
| 🤖 | AI-generated (or AI-assisted) content |
| 🧱 | Layout structure (grid/flex/containers/sections) |
| 📦 | Box model + spacing (margin/padding/border) |
| 📐 | Sizing rules + breakpoints (width/height/units) |
| 📏 | Measuring layout space (especially image “slot size”) |
| ⚖️ | “Weights” / proportions (like CSS fractions `fr`) |
| 🏁 | A key milestone in the layout (often a responsive change) |
| 📺 | Media queries / responsive behavior |
| 📱 | Phone / small screens |
| 📲 | Tablet breakpoint |
| 💻 | Laptop / medium screens |
| 🖥 | Desktop / large screens |
| 🖼 | Images / responsive images / image rules |
| 🏷 | Labels / headings / “this section is called…” |
| 📝 | Notes / explanations / reminders |
| 💡 | Tips / “try this” ideas |
| 📌 | Important callout / keep an eye on this |
| 📖 | Reading / references / “learn more” |
| 📘 | A single doc/resource link |
| 📚 | Multiple resources / study links |
| 🔗 | Links / anchors / clickable things |
| 👆 | “Click here” / interaction hint |
| 👣 | Step-by-step instructions |
| 🧭 | Navigation / “where you are” in the page/site |
| 📇 | Cards/components (reusable UI blocks) |
| 🧩 | Pieces/components working together |
| 🧰 | Tools / utilities / helper patterns |
| 🧠 | Why it works / reasoning / “think about it like this” |
| 🔤 | Typography (fonts, text styles) |
| 🔢 | Ordering/numbering (like ordered lists or sequences) |
| 🔲 | Borders/boxes/outlines (often debug styling) |
| 🔸 | Small emphasis / bullet-like note |
| 🔝 | “Back to top” / top-of-page behavior |
| 📍 | Location / positioning |
| 🧮 | Tables/calculations/data layout |
| 🌐 | Web/Internet/external site context |
| 🌿 | Nature-themed styling (often color inspiration) |
| 🌾 | Nature/earth tones (often color inspiration) |
| ☕ | Coffee example content (from list demos) |
| 🥛 | Milk example content (from list demos) |
| 🪜 | Step/ladder metaphor (usually for ordered steps) |
| 🦆 | Rubber duck example content |
| 🐶 | Dog/puppy example content |
